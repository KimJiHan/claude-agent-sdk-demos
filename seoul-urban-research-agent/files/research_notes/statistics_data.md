# 서울시 자전거 이용 현황 통계 데이터

## 전체 통계 요약 (2024년 기준)

### 공공자전거(따릉이) 운영 규모
- 따릉이 대여소 수: 2,843개소 (서울시, 2024년)
- 따릉이 자전거 대수: 45,200대 (서울시, 2024년)
- 서울시내 운영 규모: 2,800여 개 대여소 / 4만 5천여 대 (서울시설공단, 2024년)

### 자전거 도로 현황
- 서울시 자전거 도로 총 길이: 1,230.5km (서울시, 2024년)
- 자전거도로 종류별 구성 (전국, 2024년):
  * 자전거·보행자 겸용 도로: 20,660km (74.4%)
  * 자전거 전용도로: 3,735km (13.5%)
  * 자전거 우선도로: 2,252km (8.1%)
  * 자전거 전용차로: 1,107km (4%)

### 연간 이용 통계
- 2024년 따릉이 연간 이용 건수: 4,385만 건 (서울시, 2024년)
- 따릉이 10년 누적 이용 건수: 2억 5,000만 건 (2014년~2024년, 서울시)
- 서울시민 1인당 평균 이용 횟수: 약 25번 (10년 누적 기준)

## 핵심 요약

### 서울시 자전거 이용 현황의 특징

1. **급속한 성장**: 공공자전거(따릉이)는 출범 10년 만에 이용 건수가 400배 증가하며 서울의 주요 이동 수단으로 정착

2. **일일 이용 규모**: 일평균 약 120만 건 이상의 이용으로 서울시민의 일상적 교통 수단 역할

3. **인프라 확충**: 자전거 도로가 2020년대 지속적으로 확대되어 2024년 1,230.5km 달성

4. **안전성 개선**: 자전거 교통사고가 5년간 8.6% 감소하고 사망자도 30% 감소하는 추세

5. **이용 패턴 변화**: 정기권 이용자 비율이 74.8%에서 80.3%로 증가하며 수익성 개선

6. **시간대별 다양성**: 평일 출퇴근(44.3%)과 주말 여가(41.9%)로 용도 다변화

7. **전국 비교**: 서울시 따릉이 이용이 전국 공영자전거 이용의 약 2.3배로 최대 규모 유지

## 데이터 활용 노트

### 통계 신뢰성
- 모든 통계는 공식 정부 기관 및 서울시 공공데이터 포털에서 제공하는 공인된 데이터
- 시계열 데이터는 매년 업데이트되어 추이 분석 가능

### 추가 데이터 활용 가능성
- 서울시 공공데이터 포털의 API를 통해 실시간 또는 주기적 데이터 수집 가능
- 구별·대여소별 상세 데이터 다운로드 가능
- 대여이력(개인정보 제외) 원본 데이터 제공

### 주의사항
- 2024년 전체 연간 통계는 연말 확정 후 업데이트될 예정
- 자전거 이용률 통계는 별도의 서울서베이 조사 기반 (매년 8월 공표)
- 전국 자전거도로 통계는 자치구 보고 기반이므로 지자체별 집계 시점 상이 가능
