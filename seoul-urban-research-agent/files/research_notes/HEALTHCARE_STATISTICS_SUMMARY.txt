주요 발견사항 (Key Findings)
================================================================================

1. 의료 산업 시장 규모 및 성장률
   ✓ 2024년 국가 경상의료비: 213.1조 원
   ✓ 1인당 경상의료비: 412.1만 원
   ✓ 의료기기 시장 CAGR (2025-2032): 7.5%
   ✓ 디지털 헬스케어 시장 CAGR (2025-2033): 14.94%
   ✓ 홈 헬스케어 시장 성장: 73.088억 달러 → 140.072억 달러 (2024-2030)

2. 의료기관 현황
   ✓ 자치구별 의료기관 통계: 연간 공표
   ✓ 병원, 의원, 약국 현황: 정기 집계
   ✓ 의료인력 통계: 매년 12월 기준
   ✓ 데이터 출처: 서울시 데이터 포털, 건강보험심사평가원

3. 의료 서비스 이용 통계
   ✓ 입원/외래별 청구현황: HIRA 보건의료빅데이터
   ✓ 응급실 월별 이용: 서울시 월별 통계
   ✓ 응급실 요일별/구별 현황: 상세 분류
   ✓ 외래환자 수진율: 질병 및 의료이용 실태 조사

4. 의료비 지출 규모 및 추세
   ✓ 외국인 의료 관광: 1조 2천억 원 지출 (전국의 85.7%)
   ✓ 외국인 진료기관: 920개 → 1,994개 (2020-2024, 116.7% 증가)
   ✓ 시군구별 진료비 통계: HIRA에서 상세 제공

5. 특화된 의료 분야별 통계
   ✓ 암 치료: 서울아산병원이 암환자의 약 12.5% 담당
   ✓ 정신건강: 서울시정신건강통계(SMHDB) 운영 중
   ✓ 심장질환: 세계 25~46위의 주요 기관 집중
   ✓ 암 등록통계: 중앙암등록본부에서 지속 관리

6. 의료 기술 투자 및 R&D 현황
   ✓ 2023년 총 투자: 381억 원
   ✓ 바이오의료 기술 투자: 60억 원 (기술 사업화)
   ✓ 누적 투자 (2022년까지): 233억 원, 62개 과제 지원
   ✓ 국가 의료기기 R&D: 7년간 9,400억 원 투자 계획

7. 서울시 주요 의료기관
   ✓ 세계 수준의 기관 4곳:
     - 서울아산병원 (세계 25위)
     - 삼성서울병원 (세계 30위)
     - 서울대병원 (세계 42위)
     - 세브란스병원 (세계 46위)
   ✓ 대학병원: 교육·연구·고도의료 제공
   ✓ 공공의료: 서울의료원 취약층 진료

8. 의료 접근성 지표
   ✓ 의료인 밀도: 자치구별 편차 존재
   ✓ 병상 분포: 지역 간 불균형
   ✓ 응급실 접근성: 위치 정보 데이터 제공
   ✓ 지역별 응급의료 센터: 계층적 운영
