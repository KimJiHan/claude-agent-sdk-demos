# Seoul Urban Research Agent - Web Application

Next.js 기반 웹 인터페이스

## 개발 서버 실행

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 열기

## 프로젝트 구조

```
seoul-research-webapp/
├── app/
│   ├── api/              # API Routes
│   ├── components/       # React 컴포넌트
│   ├── lib/              # 유틸리티
│   └── page.tsx          # 홈 페이지
├── public/               # 정적 파일
└── styles/               # 글로벌 스타일
```

## 기술 스택

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- ESLint

## 빌드

```bash
npm run build
npm start
```
